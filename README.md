# 라즈베리파이 Edge AI 및 IoT 모니터링 시스템

본 프로젝트는 라즈베리파이 환경에서 작동하는 실시간 IoT 모니터링 및 AI 추론 시스템입니다. 물리 센서 제어, 온디바이스 TensorFlow Lite(TFLite) 추론 엔진, SQLite 데이터 로깅, WebSocket 기반의 실시간 웹 대시보드를 통합하여 구동합니다.

---

## 주요 기능

*   **FastAPI 및 WebSocket 백엔드**: 센서 쿼리 루프와 TFLite 추론을 비동기적으로 처리하며, 연결된 대시보드 화면에 1Hz 주기로 실시간 데이터를 전송합니다.
*   **온디바이스 Edge AI 추론 (TFLite)**: 온도, 습도, 거리, 모션으로 구성된 4차원 입력 데이터를 학습된 TFLite 모델에 입력하여 정상, 침입, 이상 징후 상황을 분류합니다.
*   **물리 센서 및 액추에이터 드라이버**: `RPi.GPIO` 라이브러리를 통해 다음 하드웨어를 직접 제어합니다.
    *   DHT11 온습도 센서
    *   HC-SR04 초음파 거리 센서
    *   PIR 모션 센서
    *   4채널 LED 피드백 출력
*   **데이터 수집 파이프라인**: 대시보드에서 수집 모드를 활성화하면 센서 측정값과 라벨 데이터를 SQLite 데이터베이스에 저장합니다. 수집된 데이터는 CSV 포맷으로 내보낼 수 있습니다.
*   **시스템 안정성 제어**: 센서 응답 지연 발생 시 비동기 타임아웃을 통해 서버 루프 중단을 방지하며, AI 모델 로드 실패 시 룰 기반 로직으로 자동 전환됩니다.

## 하드웨어 GPIO 핀 설정

시스템은 BCM 핀 번호 체계를 사용합니다.

| 컴포넌트 | 입출력 구분 | BCM 핀 번호 | 용도 및 설명 |
| :--- | :---: | :---: | :--- |
| **LED 1 (모션)** | 출력 | `16` | 모션 감지 시 점등 |
| **LED 2 (근접)** | 출력 | `20` | 초음파 측정 거리가 30cm 이하일 때 점등 |
| **LED 3 (조도)** | 출력 | `19` | 조도 센서 연동용 (현재 기능 미구현) |
| **LED 4 (AI 상태)** | 출력 | `26` | 메인 시스템 가동 및 추론 루프 표시등 |
| **PIR 센서** | 입력 | `21` | 인체 동작 감지 |
| **DHT11** | 입력 | `12` | 주변 온도 및 습도 측정 |
| **초음파 TRIG** | 출력 | `5` | 초음파 송신 신호 트리거 |
| **초음파 ECHO** | 입력 | `6` | 초음파 수신 신호 에코 |

## 실행 및 작동 방법

### 1. 패키지 설치
라즈베리파이 시스템 환경에서 다음 명령어를 실행하여 필수 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. FastAPI 서버 구동
Uvicorn 웹 서버를 통해 서비스를 시작합니다.
```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```
서버 구동 후 브라우저를 통해 `http://<라즈베리파이-IP-주소>:8000`에 접속하면 웹 대시보드를 확인할 수 있습니다.

### 3. 학습용 데이터셋 수집 및 CSV 내보내기
1. 웹 대시보드에 접속합니다.
2. 수집하고자 하는 상황 라벨(예: 라벨 1: 침입 상황)을 선택합니다.
3. '수집 시작' 버튼을 누르면 실시간 센서 데이터가 SQLite 데이터베이스에 기록됩니다.
4. 상황 재현 완료 후 '수집 중지'를 누릅니다.
5. 저장된 데이터를 텐서플로우 학습용 CSV로 변환하기 위해 아래 명령어를 실행합니다.
   ```bash
   python db_to_csv.py
   ```
   실행 후 루트 디렉터리에 `sensor_dataset.csv` 파일이 생성됩니다.

### 4. 시스템 장애 예외 대응 테스트
실제 하드웨어가 연결되지 않은 개발 환경에서도 센서 타임아웃이나 모델 로드 실패 등에 대한 시스템 생존성을 테스트할 수 있습니다.
```bash
python test_error.py
```
