# AIoT 독거노인 정서교감 및 스마트 돌봄 시스템

본 프로젝트는 독거노인의 고독사 예방 및 우울감 해소를 위해 라즈베리파이 환경에서 구동되는 실시간 AIoT 정서교감 및 돌봄 시스템입니다. 물리 센서를 통한 사용자 상태 및 실내 환경 계측, 온디바이스 TensorFlow Lite(TFLite) 기반 감정 및 상태 추론, 실시간 웹 대시보드를 통합하여 지원합니다.

---

## 주요 기능

*   **정서 교감 및 상태 파악 (Edge AI)**: 온도, 습도, 사용자의 접근 거리, 생활 반응(모션) 데이터를 종합하여 사용자의 현재 상태를 판단(안정, 교감, 이상 징후)합니다.
*   **FastAPI 및 WebSocket 통신**: 수집된 센서 데이터와 AI 의사결정 상태를 연결된 대시보드 화면에 1Hz 주기로 실시간 전송합니다.
*   **물리 센서 및 피드백 (RPi.GPIO)**: 하드웨어를 직접 제어하여 현실 세계와 물리적으로 소통합니다.
    *   DHT11: 실내 쾌적도(온습도) 측정
    *   HC-SR04: 사용자 상호작용 거리 측정
    *   PIR: 생활 반응 감지
    *   액추에이터(4채널 LED 대용): 감정 표현 모터 가동, 스피커 출력 반응, 취침 유도 피드백 등
*   **복지 데이터 수집 체계**: 돌봄을 위한 학습 데이터 수집 모드를 활성화하면, 상황 라벨과 센서 원시값이 SQLite 데이터베이스에 기록됩니다. 데이터는 돌봄 AI 개선을 위한 CSV 포맷으로 내보낼 수 있습니다.
*   **무중단 안전 설계**: 장마나 기기 노후화로 인한 센서 무응답 시 서버 중단을 막는 비동기 타임아웃, AI 모델 부재 시 작동하는 룰 기반 폴백 시스템을 갖추고 있습니다.

## 하드웨어 GPIO 핀 설정

기존 하드웨어 연결성을 100% 호환되도록 BCM 핀 번호 체계를 사용합니다.

| 컴포넌트 | 입출력 구분 | BCM 핀 번호 | 용도 및 설명 |
| :--- | :---: | :---: | :--- |
| **LED 1 (동작)** | 출력 | `16` | 활동 반응 / 감정 표현 모터 가동 표시 |
| **LED 2 (근접)** | 출력 | `20` | 근접 교감 / 스피커 출력 표시 |
| **LED 3 (조도)** | 출력 | `19` | 취침 환경 유도 표시 |
| **LED 4 (상태)** | 출력 | `26` | 돌봄 시스템 가동 상태 표시등 |
| **PIR 센서** | 입력 | `21` | 사용자 생활 반응 감지 |
| **조도 센서** | 입력 | `13` | 실내 조도 환경 감지 (디지털 0/1 출력 신호) |
| **DHT11** | 입력 | `12` | 실내 온도 및 습도 측정 |
| **초음파 TRIG** | 출력 | `5` | 상호작용 거리 측정을 위한 송신 트리거 |
| **초음파 ECHO** | 입력 | `6` | 초음파 수신 에코 |

## 개발 및 구동 환경

### 1. 지원 OS
- **Raspberry Pi OS 4** (또는 호환 데비안 계열 OS)

### 2. 권장 파이썬 버전
- **Python 3.9 이상** (테스트 및 구동 환경: Python 3.11)

### 3. 주요 라이브러리 의존성 및 버전
본 시스템은 `requirements.txt`에 정의된 다음 라이브러리 버전을 사용하여 구동 및 테스트되었습니다:
- **FastAPI**: `0.104.1` (비동기 웹 백엔드 서버 프레임워크)
- **Uvicorn**: `0.24.0.post1` (ASGI 웹 서버)
- **Websockets**: `12.0` (대시보드 실시간 양방향 데이터 통신)
- **Jinja2**: `3.1.2` (대시보드 HTML 템플릿 렌더링)
- **Numpy**: `1.26.2` (TFLite 추론용 데이터 배열 행렬 연산)
- **Adafruit-CircuitPython-DHT**: `4.0.12` (DHT11 온습도 센서 계측 제어)
- **Adafruit-Blinka**: `8.26.0` (라즈베리파이 하드웨어 인터페이스 지원)
- **gpiozero**: `2.0` 및 **rpi-lgpio** (라즈베리파이 GPIO 제어)
- **tflite-runtime**: 에지 AI 온디바이스 추론 가속 엔진

## 실행 및 작동 방법

### 1. 패키지 설치
라즈베리파이 시스템 환경에서 다음 명령어를 실행하여 필수 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. FastAPI 서버 구동
Uvicorn 웹 서버를 통해 서비스를 시작합니다.
```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```
서버 구동 후 브라우저를 통해 `http://<라즈베리파이-IP-주소>:8000`에 접속하면 모니터링 대시보드를 확인할 수 있습니다.

### 3. 학습용 데이터셋 수집 및 CSV 내보내기
1. 웹 대시보드에 접속합니다.
2. 수집하고자 하는 상황 라벨(예: 라벨 1: 교감 상태)을 선택합니다.
3. '수집 시작' 버튼을 누르면 실시간 사용자 상태 및 환경 데이터가 SQLite 데이터베이스에 기록됩니다.
4. 데이터 확보 완료 후 '수집 중지'를 누릅니다.
5. 저장된 기록을 돌봄 AI 최적화용 CSV로 변환하기 위해 아래 명령어를 실행합니다.
   ```bash
   python db_to_csv.py
   ```
   실행 후 루트 디렉터리에 `sensor_dataset.csv` 파일이 생성됩니다.

### 4. 돌봄 시스템 장애 예외 대응 테스트
기기 노후화나 단선으로 인한 센서 응답 지연 및 AI 오류 시나리오를 점검할 수 있습니다.
```bash
python test_error.py
```
